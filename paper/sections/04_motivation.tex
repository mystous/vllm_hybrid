\section{특성화 개요: spec-decode는 지배적이나 불균일하다}
\label{sec:motivation}

본 절은 DGX B200$\times$8 에서 10개 모델 $\times$ 4개 방법 $\times$ 7개 조건을
실 트레이스로 측정한 특성화의 개요를 제시하고, 이후 절의 두 질문
(언제 켜는가 / 무엇을 남기는가)으로 연결한다.
실험 설정은 \S\ref{sec:methodology} 에 상술한다.

\subsection{spec-decode는 단일 lever 중 가장 강하다}
\label{subsec:mot-dominant}

이질 트래픽을 모사한 mix 조건에서 suffix 는 8개 주력 모델 \emph{전체}에 대해 순 양성이며,
처리량 향상이 $+83\%$(R1-Distill-Qwen-32B)에서 $+232\%$(Llama-3.1-70B)에 달한다
(Table~\ref{tbl:b200-realtrace}).
이는 본 환경에서 검토한 어떤 단일 lever 보다 큰 이득으로,
spec-decode 가 처리량의 \emph{지배적} 결정요인임을 확인한다.

\subsection{그러나 부호가 갈린다}
\label{subsec:mot-heterogeneous}

단일 corpus 조건까지 내려가면 그림이 달라진다.
70개 (모델$\times$조건) 쌍 중 \textbf{55개에서 suffix 가 net-positive,
15개에서 vanilla 가 더 빠르다}.
Fig.~\ref{fig:alpha-gain} 은 각 셀의 suffix 수락률 $\alpha$ 대 vanilla 대비 이득을 보인다.
$\alpha$ 가 클수록 이득이 커지지만 break-even 은 단일 $\alpha$ 값이 아니다:
vanilla-win 셀(빨강)은 $\alpha\!\lesssim\!0.54$ 에 몰려 있고,
특히 추론$\cdot$MoE 모델은 중간 $\alpha$ 에서도 크게 손해다.
이 부호를 무엇이 결정하는지(\S\ref{sec:problem}),
왜 특정 모델에서 $\alpha$ 가 붕괴하는지(\S\ref{sec:mechanism})를 이후에 분석한다.

\subsection{성공이 자원 균형을 바꾼다}
\label{subsec:mot-resource}

결정적 관찰은 \emph{spec-decode 가 성공하는 곳에서 GPU 이용률이 오히려 떨어진다}는 것이다
(Table~\ref{tbl:b200-realtrace} 의 GPU\% 열: 예 Qwen-2.5-7B $82.5\!\to\!26.5\%$,
Qwen-2.5-32B $94.3\!\to\!64.8\%$).
step 수가 급감하면서 GPU 가 step 사이에 더 자주 쉬고, 그 gap 은 host 작업이 채운다.
한편 CPU 는 7B부터 671B까지 전 구성에서 $2.5\!\sim\!4.9\%$ 로 유휴하다.
즉 처리량 지배 기법이 시스템을 GPU 포화에서 host(CPU) 병목으로 전환시키며,
이 유휴 CPU 가 다음 처리량 한계를 여는 자원이 된다(\S\ref{sec:direction}).
