## 4. 해석
- HB_MIX1 은 calibration·selection·독립 입력이 모두 같은 분포(sonnet 512/128, C64)라 그 분포에서는 +6~10 % 이지만, 고정 평가 입력 MAIN_SHORT(H0 를 만든 IDE_070 트레이스 분포)에서는 −10 % 대 손실 → 배치가 calibration 분포에 과적합. 지시서의 최종 판정 입력은 고정 MAIN/C1/LONG 이므로 채택 요건을 충족하지 못한다.
- FP8 GPU ↔ INT4 CPU 실행 위치가 582 expert 에서 바뀌어 출력 분포도 뚜렷이 달라진다(수치 기준 미달).
- 비용 모델(§7)은 unique cold 예측은 맞았으나, 'MAIN_SHORT 에서의 cold 사용' 을 calibration 이 대표하지 못한 것이 원인. 워크로드 분포가 다르면 별도 배치(`HB_for_<workload>`)로 다뤄야 하며 고정-map 비교와 섞지 않는다(§9).
