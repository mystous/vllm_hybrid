## Context

IDE_030 에서 얻은 성능 결과 (hot-96 + deferred 4: C=32 490.9 tok/s, +53.5%, GSM8K 100문항 97.0%) 는 기존 기법의 설정·튜닝이라 그 자체로는 연구 결과가 아니다. 다만 그 과정의 측정 (480B CPU 층 호출 마이크로벤치 = expert당 55µs 스트리밍 + 행당 19µs, DDR 실측 천장 ~430 GB/s, 라우팅 트레이스의 distinct cold expert 기대값, hot↔KV 메모리 교환 관계) 은 8-30 에 56% 오차로 기각된 스펙-only 배치 하한 모델 (`IDE_029/PLN_006`) 이 놓친 항들을 채운다. 이를 **마이크로벤치 파라미터만으로 하이브리드 MoE 서빙 스텝 시간을 사전 예측하는 기계 모델 + GPU 메모리 분할 (hot expert vs KV, KV 를 DRAM 으로 내릴지) 정책** 으로 발전시켜 연구 결과로 만든다. 목표 venue 는 시스템 워크샵 8쪽 (사용자 결정). 탑티어는 범위 밖 (새 메커니즘 없음).

사용자 결정 (2026-09-08): M2 는 SGLang HiCache (DRAM KV tier) 통합까지 / venue 워크샵 / 평가 모델 480B + 235B + 30B / K1 22편 전문 정독.

심사위원 관점 검토 (분신) 반영 사항: 주장 1 을 "전이점" 형태로 수정, 모델 항 6개 추가, 사전 예측 셀 선정·반복 규칙 추가, 일정 4~5주로 현실화, K1 의 최대 위협 = FlexGen (KV·가중치 배치 비율의 LP 동시 결정) 과 MoE-Lightning (HRM) — K1 을 먼저 통과해야 나머지가 의미 있음.

> **K1 판정 (09-08 13:00, 21/22편 전문 — `K1_DELTA.md`)**: D1 부분 선행 3편 (MoE-Lightning·MoE-Gen: PCIe 예산 하 비율 공동 결정 / CoX-MoE: VRAM 용량 하 AMX cold + GPU hot 상주 공동 결정) → 사전 규칙대로 **주장 ③ 을 보조로 강등**. D2 형식 선례 = MoE-Lens (하이브리드 MoE, 평균 94%), 사전등록·셀별 오차 분포는 0건. D3 전이점 선행 3편은 KV 용량·k·micro-batch 축 — **H 축 없음**. DDR 공유 항은 MoE-Lens Eq.5 에 이미 존재하나 비-binding 결론. → 주장 재배치: ① H 축 전이점 사전 예측 (유지) ② 사전등록·셀별 오차 분포 (유지, 형식 delta) ③ "DDR 대역폭이 binding 인 워크로드 (HiCache 멀티턴·같은 소켓) 에서 최적 분할이 바뀜을 사전 예측" — MoE-Lens 의 비-binding 결론을 뒤집는 실증이 없으면 각주 수준으로 격하. 무대 (온라인 TPOT) 와 토폴로지 (CPU cold expert) 는 CoX-MoE 와 겹치므로 단독 delta 로 주장하지 않는다.

- 질문: GPU 메모리를 hot expert 와 KV 에 어떻게 나눌지를, "GPU 밖으로 나간 것 (cold expert 스트리밍·offload KV 읽기) 은 같은 DDR 대역폭을 소모한다" 는 공통 예산 아래 결정하면 처리량이 얼마나 오르고, 그 결정을 측정 전에 예측할 수 있는가.
- 주장 1 (수정): hot expert 수 H 에 따라 binding 자원이 DDR 대역폭 (H 작음) 에서 GPU expert 연산 (H 큼) 으로 바뀌는 **전이점**이 있으며 (hot-80: CPU 대기 40ms / hot-96: GPU 27.7 vs CPU 9.9ms 실측), 모델이 그 위치를 예측한다.
- 주장 2: 마이크로벤치·트레이스 파라미터만으로 (배치, H, KV 위치, 컨텍스트) 격자의 스텝 시간을 사전 예측 (중앙값 오차 ≤20%).
- 주장 3: 모델이 고른 분할이 워크로드 (동시성·컨텍스트) 마다 다른 답을 내고 그 답이 실측으로 맞는다 — HiCache 없이는 반증될 수 있으므로 (C=64 에서도 hot-96 이 +20%) M2 필수.
- K1 결과에 따라 delta 가 "MoE 서빙 + 사전등록 예측 + 전이점" 으로 좁혀질 가능성 높음 (FlexGen 이 dense 에서 결합 LP 를 이미 함).
