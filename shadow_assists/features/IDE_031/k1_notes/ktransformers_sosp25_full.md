# KTransformers (SOSP '25) — 전문 판정 (2026-09-08 14:10, 사용자 반입 PDF `papers/KTransformers_SOSP25_3731569.3764843.pdf`)

- 서지: Chen et al., "KTransformers: Unleashing the Full Potential of CPU/GPU Hybrid Inference for MoE Models", SOSP '25, DOI 10.1145/3731569.3764843. 전문 16쪽 확보 (pypdf 추출 `papers/KTransformers_SOSP25.txt`).
- 무대·결정 변수: 로컬 배포, **"batch size of 1, representing the most typical local deployment"** (p.11). 배치: "this paper focuses on models with shared experts, which naturally emerge as the most frequently-used experts and are therefore placed on the GPU, while routed experts ... are offloaded to the CPU" (p.2). hot expert 수는 변수가 아님 — "for models without shared experts, popular experts can still be identified via offline profiling, as done in Fiddler" (언급만).
- 기여: ① AMX 커널 (ARI 기반 AMX/AVX-512 선택, 타일 정합 레이아웃) ② CUDA graph 안 CPU 스핀 동기화 ③ NUMA 복제 ④ **Expert Deferral** ("only a subset of experts (immediate experts) are processed immediately, while the remaining experts (deferred experts) are scheduled concurrently with the computation of the subsequent layer (primarily the attention module)", O_k = I_k + S_k + R^def_{k-1}(I_{k-1}) + R^imm_k).
- 비용 모델·예측: 없음. deferral 개수는 단일 층 타임라인 실측: "we conducted a comprehensive performance analysis of a single DeepSeek-V3 layer" → 2/3/4 deferral 실험, "deferring 4 experts provided no further throughput benefits due to CPU saturation" → 휴리스틱 "deferring the minimum number of experts required to achieve full CPU utilization while ensuring at least 2 immediate experts per layer" (p.9).
- KV·DDR: KV 는 GPU. DDR 대역폭은 배경 ("a dual-socket Intel Xeon system with DDR5 memory can offer 440 GB/s") 과 NUMA 절 ("memory bandwidth is 220 GB/s, while cross-socket ...") 에서 하드웨어 사실로만.
- D1: **아니오** (expert 상주 수·KV 배치 결정 없음). D2: **아니오** (성능 모델·예측 없음, 실측 speedup 만). D3: **아니오** (CPU 포화 휴리스틱; H 축 없음, 배치 1).
- 우리와의 delta: 기반 시스템. H 를 정하는 모델·KV 결합·사전 예측·전이점·온라인 배치 서빙 (C=8~64) 이 빈자리. 주의: 그들의 deferral 창 ("concurrently with ... the attention module of the subsequent layer") 은 우리 topk 덤프 기전 (MoE 이전 창) 과 일치 — 우리 모델 항의 근거로 인용.
