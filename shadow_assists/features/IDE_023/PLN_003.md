- **기존 측정 노드와 별개** — vLLM 컨테이너/이미지 부재 (cuda-base 만 존재) → baseline re-anchor (`TSK_046`) 필수

- k8s 워커 — 컨테이너는 nerdctl `default` namespace, `--net host`
- 인터넷 ~105MB/s (70B 68GB 11분 실측)
