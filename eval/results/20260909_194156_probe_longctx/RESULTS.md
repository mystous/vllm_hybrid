# 탐침 — 긴 컨텍스트 (sonnet 2048/128, prefix 100) 최종 구성 (운영점 B + FUSE, 혼합 forward 없음)

| 동시성 (프롬프트 3×C) | tok/s (출력) | TPOT ms | TTFT s | 512/128 기준 |
|---|---|---|---|---|
| C48 | 290.3 | 108.5 | 7.38 | (C64 796.6 / 57.6) |
| C32 | 301.9 | 66.3 | 5.15 | 578.0 / 37.2 |
| C16 | 111.9 | 121.0 | 2.94 | — |

- 입력 4배 (512 → 2048) 에서 출력 처리량 약 1/2 (C32 578 → 302). 요청 시간이 prefill (C48: 98k 프롬프트 토큰 = 청크 24개, ≈7.4 s) 에 지배되고 decode TPOT 자체는 정상 (C32 66 ms).
- C16 의 TPOT 121 은 파도별 prefill (16×2048 = 청크 8개 ≈ 3 s) 이 앞 파도의 decode 를 끊는 효과 (혼합 forward·delayer 로 완화되는 종류).
- 의미: 긴 컨텍스트에서는 prefill 의 GPU 비중이 커지지만 하이브리드 prefill 의 CPU 고정비 (cold expert 스트리밍) 는 청크 수에 비례해 그대로 누적 → prefill 청크를 크게 (8192) 하는 것이 유리하나 GPU 메모리 (중간 버퍼) 와 교환. 특성화 기록용, 채택/기각 대상 아님.
