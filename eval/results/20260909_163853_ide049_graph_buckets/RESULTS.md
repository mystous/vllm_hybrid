# IDE_049 — CUDA graph 버킷 축소로 GPU 메모리 회수 → KV 확대 → C192 — **채택**

관찰 (IDE_047): `--cuda-graph-bs` 를 6종으로 명시하면 기본 39종 대비 수 GB 회수. 최선 구성 (hot-96 α0.25, CF+τ, AMX 선택, `KT_AVX_RB=1`, FP8 KV, mem 0.94) 에 적용.

| 구성 | KV 토큰 | C224 | C192 | C160 | GSM40 |
|---|---|---|---|---|---|
| 버킷 7종 (32..224), graph 224, KV 요청 143k, 청크 8192 | 127,309 | 첫 prefill OOM (768 MB) → 실패 | | | |
| **버킷 6종 (32 64 96 128 160 192), graph 192, KV 122,880, 청크 8192** | 122,880 | — | **1032.6 / 133.5 / TTFT 6.83s** | **994.6 / 116.6 / 5.77s** | 97.5 |
| 기준 (IDE_039-i: 39종 버킷, graph 160, KV 110,592) | 110,592 | — | — | 982.4 (오늘 965~985) / 119.5 | 97.5 |

- C192: 기존 최고 982.4 대비 **+5.1%** (사전 등록 ≥1,030 통과). 모델 예측 (+6%) 과 일치: cold expert 22 → 26개 (+13% CPU) 에 토큰 +20%.
- C160: 994.6 / 116.6 — 오늘 최고. KV 123k 라 160×640 = 102k 가 여유 있게 들어가 admission 파도가 사라짐.
- 인과 (CPU 측): 같은 스트리밍 (cold expert 당 24 MB) 으로 더 많은 토큰을 처리 — expert 당 평균 행 수 1.27 → 1.3+.

부팅 후 GPU 메모리 78.8 / 80 GB. 청크 8192 의 fused_moe 중간 버퍼 (768 MB) 가 한계. 다음: 청크 4096 으로 버퍼를 줄여 C224 재시도 (IDE_049-b).
