# IDE_048 — AVX-512 vec 경로 (decode 1~2행) 레지스터 블로킹 — 진행 중 (서빙 대기)

원본 `GemmKernel224Int4::avx_kernel`: 누산기 `c512[]` 가 메모리, 행마다 B 언팩 반복 → dpbssd 체인 latency-bound.
새 커널 `avx_kernel_rb` (`KT_AVX_RB=1`): k-group 당 B 4벡터 1회 언팩, 8/4/2/1 행 블록 누산기를 zmm 에 유지, 1행은 4분할·2행은 2분할 K 누산기 (체인 8개). 정수 누산 → **bit 동일** (T=8/40/200 n_cold 8, T=1024 n_cold 64: max abs diff 0).
