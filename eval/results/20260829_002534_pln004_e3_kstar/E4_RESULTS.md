Δ vs G=0 (동일 K): G32 = −4.0% / **+1.6% / +4.1%** (K 에 단조 증가) · G64 = −0.1% / −2.4% / −4.0% (K 에 단조 감소)

## 판정

1. **(G,K) 표면은 비분리 (non-separable)** — argmax_G 가 K 에 의존: K=0 에선 G 배치가 무익/유해, K≥3 에선 G=32 가 우위, G=64 는 과잉. **"배치는 K 와 공동 최적화해야 한다" (SCED 명제) 의 1차 실증**
2. 방향성은 이론 정합: spec 증폭 (T↑) 이 GPU-상주 expert 의 토큰 상각을 개선 → G32 이득이 K 에 단조. 과잉 배치 (G64) 는 CPU 병렬성 (NUMA 2-pool) 활용 감소로 역효과 추정
3. **효과 크기 주의**: ±4% 수준 — 단일 run jitter (±3% 추정) 와 인접. 3-run 재현이 논문 인용의 전제 (후속)
4. 전역 최고 817.3 tok/s = 배치+spec 결합 (G32-K3) — G0-K0 대비 **1.48×**
