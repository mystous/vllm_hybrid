- 목적: "머신 1대 = 대형 모델 2개" (GPU 4+4 + CPU expert) 의 간섭 실측 — `brainstorming/problem_search_20260829.md` 후보의 K2 게이트

## 재사용 지식

1. **다중 kt-hybrid 배치 필수 절차**: 인스턴스별 컨테이너 + `--cpuset-cpus <소켓 코어> --cpuset-mems <노드>` (numactl 은 kt 에 안 통함). 재현 스크립트: `setup_kt_container.sh` + `run_k2_final.sh`
2. **kt-kernel 결함 (upstream 제보 대상)**: CPUInfer 절대-pin — 다중 인스턴스·컨테이너 환경에서 최대 115× 붕괴 유발
3. 가중치 mmap 공유는 무해 (fin 에서 두 인스턴스가 같은 232GB 를 공유하며 무간섭) — DRAM 은 한 벌 분량만 소요
4. 운영 사고 기록: `docker commit` 이 컨테이너를 pause 시킨 채 클라이언트 타임아웃 → 침묵 정지 (unpause 로 복구)
